## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → lifecycle API | Snapshot/resize/clone/migrate/bulk mutations carry the CSRF token |
| rendered snapshot/error text | Snapshot names and PVE-derived text rendered in the browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06-01 | Spoofing / CSRF | Snapshot/resize/clone/migrate/bulk mutations | mitigate | All `api.lifecycle.*` calls route through the `apiJson` client which attaches the double-submit CSRF token; the backend enforces `csrf_protect` on every mutating route. |
| T-03-06-02 | Cross-Site Scripting | Snapshot name / description / error text rendered in the tree and dialogs | mitigate | All PVE-derived strings are rendered via Svelte text interpolation (auto-escaped); no `{@html}` anywhere in SnapshotTree, the dialogs, or the inventory list. |
