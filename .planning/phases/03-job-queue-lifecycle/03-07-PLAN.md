- PUT  /api/v1/clusters/{id}/vms/{vmid}/backup-schedule  body {enabled,frequency:"daily"|"weekly",keep_last} → 200
- GET  /api/v1/clusters/{id}/vms/{vmid}/backup-schedule → schedule row
- DELETE /api/v1/clusters/{id}/vms/{vmid}/backups/{volid} → 202

- GET  /api/v1/clusters/{id}/backup-storages → admin: backup-capable storages for the cluster
- PATCH /api/v1/clusters/{id}  body {backup_storage:"..."|null} — sets the admin backup-storage preset

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → backup/restore API | Backup/restore/schedule mutations carry the CSRF token |
| browser → admin cluster API | The backup-storage PATCH is admin-only |
| /backups SSR loader | Server-side render with the session cookie |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07-01 | Spoofing | Unauthenticated access to /backups | mitigate | The `+page.server.ts` loader re-checks `locals.user` and `throw redirect(303, '/login?next=...')` — defense-in-depth, copied from the audit page. |
| T-03-07-02 | Spoofing / CSRF | Backup/restore/schedule mutations | mitigate | All `api.lifecycle.*` calls route through `apiJson` which attaches the CSRF token; the backend enforces `csrf_protect`. |
| T-03-07-03 | Elevation of Privilege | Non-admin setting the backup storage | mitigate | The backup-storage Select lives on the already-admin-gated `/admin/clusters/{id}` page; the backend `PATCH /clusters/{id}` and `GET /clusters/{id}/backup-storages` are admin-gated. |
| T-03-07-04 | Information Disclosure | The /backups page leaking another team's schedules | mitigate | `GET /backups/schedules` is team-scoped server-side (Plan 04 — `_team_ids_for_user`); the page renders only what the server returns. |
| T-03-07-05 | Tampering | Restore-as-new bypassing quota | mitigate | The UI submits the request; the Plan 04 backend runs quota admission on restore-as-new before enqueue. The UI quota-delta line is informational only. |
| T-03-07-06 | Cross-Site Scripting | Backup filename / cluster name rendered in tables | mitigate | All strings rendered via Svelte text interpolation (auto-escaped); no `{@html}` in BackupsTab, RestoreDialog, or the /backups page. |
| T-03-07-07 | Information Disclosure | In-place restore destroying data without intent | mitigate | The Restore dialog defaults to in-place but gates the destructive CTA behind a typed-name confirm (D-10); the backend still authorizes via `require_resource_access`. The typed-name is a UX affordance; authorization is the enforcement. |
</threat_model>
