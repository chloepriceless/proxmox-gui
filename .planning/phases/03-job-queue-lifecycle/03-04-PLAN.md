<objective>
Add the heaviest lifecycle operations onto the proven pipeline: backups (manual vzdump + scheduled via arq cron with keep-last-N retention + restore in-place/as-new), clone (linked/full with app-reserved VMID + quota admission + template conversion), and migrate (live/offline with bwlimit + quorum pre-flight + node-local snippet pre-flight). Adds the per-cluster admin backup-storage designation and the `backup_schedules` ORM model.

Purpose: Complete the lifecycle operation set; layer the complex multi-step ops on the validated job pipeline.
Output: Backup/clone/migrate backend endpoints, the scheduled-backup cron, the migration pre-flights, and the admin backup-storage config.
</objective>
