<objective>
Build the Phase-4 frontend API foundation and shared primitives: the five typed API client modules, the two shared primitives (`EmptyState`, `HelpTooltip`), and the `/inventory` Create button + empty state. This plan owns the API layer and shared components so the wizard-shell plan (04-10) and every wizard-step plan (04-11/12/13) can build against typed clients without conflict.

Purpose: Every Phase-4 frontend surface needs typed API clients (04-PATTERNS.md — `lifecycle.ts` is the exact analog). UI-04 needs a reusable `EmptyState`; UI-05 needs a reusable `HelpTooltip`. Splitting the API layer + primitives into this plan (and the wizard shell into 04-10) keeps each plan under the file-count threshold and keeps `routes/create/+page.svelte` owned by exactly one plan per wave.

Output: `api/{provisioning,catalog,networks,iso,console}.ts`, the appended `types.ts`, `EmptyState.svelte`, `HelpTooltip.svelte`, and the `/inventory` "Create" button + empty state.
</objective>
