<objective>
De-risk the single highest-risk Phase 4 domain: non-interactive execution of a community-script's per-app install stage inside a GUI-created LXC. This is research Assumption A1/A2 (HIGH risk) and ROADMAP-mandated spike 3.

Purpose: RESEARCH.md flags that the community-scripts canonical flow drives `build.func` — an interactive `whiptail` orchestrator the GUI must NOT run (Pitfall 10). The GUI's model is "create the empty LXC ourselves, then run only the install stage inside it via `pct exec`". Whether that install stage runs standalone is unknown and gates LXC-03. This spike resolves it before 04-06 is implemented.

Output: `04-SPIKE-community-scripts.md` — a findings document with a go/no-go decision, the confirmed exec mechanism, the metadata format, a pinned commit hash, and the attribution format. No production code ships in this plan; it produces the contract that 04-06 implements against.
</objective>
