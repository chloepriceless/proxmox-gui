<objective>
Close WR-01 (WARNING — in scope per user decision): supply-chain hardening for the
community-scripts execution path. `backend/app/jobs/provisioning_functions.py`
`_build_install_command` (line ~145) interpolates `commit_sha` (from the `catalog_pin`
row) into a raw GitHub URL (`{_SCRIPTS_REPO_RAW}/{commit_sha}/install/{slug}-install.sh`)
and into a shell command WITHOUT validating it is a 40-char lowercase hex SHA-1. `slug`
is interpolated into the same URL/command unvalidated. CLAUDE.md constraint #8 ("Pin to
commit hashes") is not fully closed — a malformed/malicious `commit_sha` or `slug` is a
supply-chain / path-traversal / shell-metacharacter injection surface.

Validate `commit_sha` against `^[0-9a-f]{40}$` and `slug` against the catalog safe
charset before either is ever interpolated. A bad value fails the job fast with a clear
explanatory error.

Purpose: close the CLAUDE.md constraint #8 supply-chain hole that protects LXC-01..04.
Output: validation guards in `provisioning_functions.py` + tests proving fail-fast.
</objective>

<constraints>
- CLAUDE.md constraint #8: "Community-scripts must run via `pct exec` inside the freshly-
  created LXC, never on the host. Pin to commit hashes." — a `commit_sha` that is not a
  real 40-char SHA-1 is not a valid pin.
- A git SHA-1 commit hash is exactly 40 lowercase hexadecimal characters: `^[0-9a-f]{40}$`.
- The catalog `slug` is a community-scripts slug — lowercase alphanumeric plus hyphens
  (e.g. `plex`, `home-assistant`, `nextcloud`). The safe charset is `^[a-z0-9][a-z0-9-]*$`
  (must start with an alphanumeric; no leading hyphen, no path separators, no shell
  metacharacters, no `..`). This prevents path traversal in `install/{slug}-install.sh`
  and shell injection in the `bash -c` string.
</constraints>

       ```python
       def _validate_commit_sha(value: str) -> str:
           """Reject a commit_sha that is not a 40-char lowercase hex SHA-1.

           Defense at the use site (WR-01 / CLAUDE.md #8) — the catalog_pin SHA is
           interpolated into a GitHub raw URL and a shell command; an unvalidated
           value is a supply-chain / shell-injection surface.
           """
           if not isinstance(value, str) or not _COMMIT_SHA_RE.match(value):
               raise ValueError(
                   "Invalid community-script commit hash — expected a 40-character "
                   "lowercase hex commit SHA."
               )
           return value

       def _validate_slug(value: str) -> str:
           """Reject a slug that is not lowercase-alphanumeric-plus-hyphen.

           The slug is interpolated into install/{slug}-install.sh and a bash -c
           string — an unsafe charset is a path-traversal / shell-injection surface.
           """
           if not isinstance(value, str) or not _SLUG_RE.match(value):
               raise ValueError(
                   "Invalid community-script slug — expected lowercase letters, "
                   "digits and hyphens only."
               )
           return value
       ```
