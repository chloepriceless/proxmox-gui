Build the networks backend: the SDN read methods, the SDN-aware picker service, the per-team network-scoping CRUD, and the routes. This is the spike-gated networking half — the read-API contract is pinned by spike 04-02 (`04-SPIKE-sdn.md`).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → API → PVE SDN reads | SDN reads run as the per-tenant team token |
| admin → team network-scoping CRUD | Only an admin may grant a team SDN visibility |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07-01 | Information disclosure | Cross-tenant SDN visibility | mitigate | `list_networks_for_team` filters SDN VNets through `get_team_network_scope` — a team sees only the VNets an admin explicitly granted (D-19); the picker route is team-scoped (`get_for_team`); cross-tenant access → 403/404 |
| T-04-07-02 | Elevation | Network-scoping CRUD by a non-admin | mitigate | `GET`/`PUT /admin/teams/{tid}/clusters/{cid}/networks` carry `Depends(require_admin)` (+ `csrf_protect` on the write) — only an admin grants network visibility; a non-admin → 403 |
| T-04-07-03 | Tampering | Granting a non-existent / cross-cluster VNet | mitigate | `set_team_network_scope` writes are keyed by `cluster_id`; the admin GET returns only that cluster's real SDN/bridge inventory so the admin UI offers only valid grants; the composite UNIQUE index keeps the grant set consistent |
| T-04-07-04 | Denial of service | Partial-node-offline SDN read hard-fail | mitigate | `list_networks_for_team` wraps the SDN reads in the Phase-2 stale-cache graceful-degradation pattern — an out-of-quorum cluster degrades to the reachable subset (or legacy bridges only) instead of erroring the whole picker (Pitfall 8) |
| T-04-07-05 | Spoofing | A pending (not-applied) VNet presented as usable | mitigate | Each VNet entry carries an `applied` flag derived from the spike's `APPLIED STATE READ:` mechanism — a not-yet-applied VNet is surfaced as non-pickable, never offered for a real create |
</threat_model>
