    UI-03 — Mobile & accessibility:
    1. On a phone (or device emulation), open the inventory list, a VM detail, and
       a console. Confirm: hamburger drawer opens the full nav; the inventory list
       is a tappable card stack; the console scales to fit; /create shows the

    AUTH-06 — Idle session timeout:
    2. Log in. In the admin Settings page, set the idle timeout to a short value
       (e.g. 3 minutes) and save. Leave the tab idle. Confirm: ~2 minutes before
       the deadline a countdown toast with "Stay signed in" appears; clicking it
       extends the session. Then let it fully expire — confirm a modal overlay
       appears, you re-auth in place, and you are exactly where you were (no
       redirect, no lost state).
    3. Confirm a PAT (automation) is NOT affected by the idle timeout (D-05).

    AUDIT-06 — Audit retention:
    4. In the admin Settings page, confirm the audit-retention value is editable.
       On the admin Audit page, confirm the archive list section renders (it may
       be empty until the nightly cron runs — if any archive exists, confirm the
       download link works).

    DEPLOY-04 — Self-update:
    5. From the admin Settings page, trigger "Update now". Confirm: the UI shows
       an updating/reconnecting state, survives the API restart blip, and reloads
       healthy on the new code. (If no newer tagged release exists, verify the
       update job runs, the SHA-256 check passes, and the health check confirms
       the same version — a no-op update should still complete cleanly.)
    6. From the PVE host, re-run `install.sh` against the existing CTID (or with
       --update). Confirm it updates the LXC in place instead of failing, and the
       GUI comes back healthy.

       available. (Spot-check the preflight gate behaviour.)

    Carryover spot-checks:
    9. Confirm a cluster's TLS fingerprint was captured at registration and the
       connection still works (D-20). Confirm an `ssh-rsa` SSH key can be added.
